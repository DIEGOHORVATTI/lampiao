# Bibliotecas de assets prontos

Fontes para pegar ícones, sons, modelos, animações e texturas sem produzir do zero. Antes de
usar qualquer arquivo, confira a licença na página de download (uploads de comunidade às vezes
vêm com licença errada) e registre o crédito em `CREDITS.md`.

Legenda de licença: **CC0** = livre, sem crédito obrigatório · **CC BY** = livre com crédito ·
**própria** = ler os termos.
